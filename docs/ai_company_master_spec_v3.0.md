### 0. 最重要ミッション
KPOP JOURNALを、**データドリブンで自律改善する収益最大化AIメディア企業OS**として運用する。

目的:
1. 毎日安定して高品質記事が自動投稿される
2. 誤投稿・審査レポート投稿・質問文投稿をゼロにする
3. 検索流入とX流入を両立する
4. 記事単位ではなく、カテゴリ単位・事業単位で収益を最大化する
5. トークンコストを抑えながら利益率の高い運用にする
6. 日次・週次・月次で経営判断ができる状態にする
7. 将来的に月商100万円超、さらにバイアウト/法人化に耐える運営基盤にする
8. 全ての実行データを計測し、フィードバックループで自律改善する
9. 投稿→計測→改善のサイクルを24時間以内に回す
10. ミュウツーの戦略判断を起点とし、全パイプラインが「何を書くべきか」から始まる
11. **【v3.0追加】「稼ぐ」に直結しない機能は後回し。全改善はROI順で優先する**

### 1. 経営理念

理念は「かけふ＋まわす」。

- か：稼ぐ — 収益を最大化する
- け：削る — 無駄なコスト・重複を排除する
- ふ：防ぐ — 誤投稿・炎上・品質低下を防ぐ
- ま：回す — 計測→分析→改善のサイクルを止めない

行動原則:
- 自立して動け
- 止めるな
- 改善しろ
- ただし壊れたものは出すな
- 迷ったら止めるより警告付きで前進
- 速報は「本当に速報であるもの」だけ速報として出す
- 資産記事は品質優先
- 収益記事はCV優先
- 投稿より「正しい投稿」を優先
- 計測できないものは改善できない。全アクションにメトリクスを。
- 昨日のデータが今日の判断を変える。フィードバックなき実行は惰性。
- 同じネタを繰り返すな。直近3日間の投稿と被らないテーマを選べ。
- エージェントが失敗しても全体は止めるな。フォールバックで前進せよ。
- **【v3.0追加】全面リファクタ禁止。最小差分で改善し、既存パイプラインを壊さない。**

### 8. サムネイルルール（v3）

**【v3.0全面改訂】固定テンプレ背景 + テンプレ文言 + WebP**

#### 基本仕様
- サイズ：1200×630px
- 出力形式：**WebP**（quality=85）+ JPEG（quality=95、フォールバック）
- フォント：Noto Sans JP Black（メイン）
- 背景：カテゴリ別固定テンプレート画像

#### カテゴリ別背景テンプレート（`assets/thumbnails/`）
| ファイル | 用途 | デザイン |
|---------|------|---------|
| news.png | 速報・ニュース・炎上 | 赤×黒、ストライプ、緊急感 |
| comeback.png | カムバック・デビュー・ファッション | 紫×青、ネオン、スパークル |
| analysis.png | 解説・考察・チャート・ランキング | 黒×ゴールド、エディトリアル |
| live.png | ライブ・イベント・旅行 | オレンジ×ピンク、ボケ、光 |
| beauty.png | 美容・コスメ・スキンケア | 白×ピンク、清潔感 |

#### テキストルール（厳守）
- **最大2行、1行あたり最大10文字**
- 強ワード必須：衝撃／速報／判明／神／炎上／ついに／電撃／復活／決定／解禁
- 数字があれば優先（6冠／13年ぶり）
- アーティスト名を含める
- 誤字ゼロ

#### 文言生成方式
- **一次生成：テンプレート選択**（`lib/thumbnail_templates.py`）— Claude不要
- 二次生成（スコアNG時のみ）：Claude 1回リトライ
- 最終フォールバック：タイトルから自動抽出（2行×10文字）

#### テンプレート例
```
breaking: "{artist} 衝撃の{event}" / "ついに判明した真相"
comeback: "{artist} ついに復活" / "{number}ぶりの復活"  
beauty:   "{artist}の神肌が衝撃" / "衝撃のコスメ{number}選"
chart:    "{artist} {number}冠の衝撃" / "歴代記録更新の衝撃"
```

#### レイアウト固定
- テキスト：中央揃え、垂直中央
- セーフエリア：x=80〜1120, y=80〜550
- 白テキスト＋黒ストローク2px（beauty系は暗色テキスト＋白ストローク）
- ドロップシャドウ付き
- 左上：KPOP JOURNALロゴ（白ピル型）
- 右上：カテゴリバッジ
- 下部：白アクセントバー

#### スコアリング（`score_thumbnail_text.py` v3）
- 通過基準：5点以上
- 行数チェック（2行以内）、各行10文字以内、強ワード必須、数字、アーティスト名で加点
- 弱ワード・コロンで減点

### 10. CTA（収益導線）強制挿入

**【v3.0新設】全記事CTA保証**

#### 方針
- CTAは任意ではなく**強制**
- 記事タイプ別に最適なCTAを自動選択
- 挿入失敗時はフォールバックCTAを注入

#### カテゴリ別CTA自動選択
| カテゴリ | CTA種別 | 内容 |
|---------|---------|------|
| ストリーミング系キーワード | ABEMA | ABEMAプレミアム無料トライアル |
| 美容（カテゴリ12） | COSMETICS | Qoo10韓国コスメアフィリエイト |
| 旅行（カテゴリ11,70） | TRAVEL | Expedia/楽天トラベルアフィリエイト |
| その他全記事 | INTERNAL | 「あわせて読みたい」同カテゴリ内部リンク3本 |

#### 実装フロー
1. 投稿完了後に `inject_revenue_links.sh` + `inject_abema_cta.sh` を実行
2. **CTA存在確認ステップ**（v3.0新設）：WP APIで公開記事を取得し、CTA div の存在を確認
3. CTA未挿入の場合 → カテゴリに応じたフォールバックCTAを自動注入
4. `has_cta: true` は実際にCTAが存在する場合のみ記録

#### 収益構造
- AdSense: 全記事に自動挿入（メイン収益源）
- A8.net: ABEMA CTA + 美容案件
- Amazon Associates: K-POPグッズ・アルバム
- 楽天アフィリエイト: 旅行・ホテル・チケット
- ASPマッチング: `config/revenue_config.json` でカテゴリ別に最適ASPを自動選択

### 19. 監査・障害対応

- タイトルなし / 本文なし / 質問文 / 審査文 / HTML破損

- 連続失敗3回 / 日次エラー5件 / WP API 5xx 3回 / トークン予算超過
