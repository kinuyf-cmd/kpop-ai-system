## プロフィール系 勝ち筋タイトルテンプレート5種

### 1. 基本型
```
[グループ名]とは？[メンバー数]人のプロフィールと代表曲【2026年版】
```
**用途**: 初めて知る読者向けの入門記事。「〜とは？」は検索意図と直結しCTRが高い。  
**例**: 「aespaとは？4人のプロフィールと代表曲【2026年版】」  
**ポイント**: メンバー数を数字で入れると具体性が増す。年号は更新時に変更すること。

---

### 2. 人気理由型
```
[グループ名]はなぜ人気？メンバー・代表曲・特徴まとめ
```
**用途**: 「なぜ人気なのか知りたい」読者向け。ファン以外の検索流入を獲得できる。  
**例**: 「IVEはなぜ人気？メンバー・代表曲・特徴まとめ」  
**ポイント**: 「なぜ」という疑問系はクリック意欲が高い。疑問→解決の構造を本文でも維持。

---

### 3. 入門型
```
[グループ名]の基本を5分でわかる｜プロフィール・代表曲完全ガイド
```
**用途**: 時間のない読者・ライトなファン予備軍向け。「5分でわかる」で読了率が上がりやすい。  
**例**: 「SEVENTEENの基本を5分でわかる｜13人の構成・代表曲完全ガイド」  
**ポイント**: 「完全ガイド」は検索ボリューム大。ハブ記事やロングフォームに向く。

---

### 4. 比較型
```
[グループA]vs[グループB]の違いとは？世代・スタイル・代表曲で比較
```
**用途**: 「どちらが〜？」という比較検索や、複数グループを知りたい読者向け。  
**例**: 「BTSvsSEVENTEENの違いとは？世代・スタイル・代表曲で比較」  
**ポイント**: 比較型は「vs」「違い」「どっちが」の検索で流入。中立的な書き方が重要。

---

### 5. 最新型
```
[グループ名]【2026年最新】現在の活動状況・ツアー・新曲情報まとめ
```
**用途**: 「最新情報が知りたい」読者向け。特に高リスク（BTS・NewJeans等）記事に適用。  
**例**: 「BTS【2026年最新】現在の活動状況・ツアー・新曲情報まとめ」  
**ポイント**: 年号を冒頭または末尾に入れることで鮮度アピール。定期更新前提のフォーマット。  
**注意**: BTS・NewJeansは活動状況断言禁止。「〜とされています」「〜予定」等に緩和すること。

---

## タイトル作成時の共通ルール

1. **文字数**: 30〜40文字が目安（スマホSERPで切れないため）
2. **数字の活用**: メンバー数・年号・「5分で」等の数字はCTRを高める
3. **「とは？」の活用**: 初心者検索と相性が良い定番フォーマット
4. **年号更新**: 毎年1月〜2月に【20XX年版】【20XX年最新】を更新する
5. **断定回避**: 活動状況・ツアー情報は「〜予定」「〜とされています」に緩和
6. **ハブとの差別化**: ハブ記事は「完全ガイド」「まとめ」を使い、個別記事とキーワードを分ける
