# 記事投稿ルール & 憲法

## 記事品質基準

### 最低要件（BLOCK条件）
- タイトルなし → BLOCK
- 本文なし → BLOCK
- 質問形式の出力 → BLOCK
- HTMLタグ破損 → BLOCK
- 文字数不足:
  - 速報記事: 最低 2,000文字
  - 通常記事: 最低 2,500文字
  - 分析記事: 最低 4,000文字
- h2見出し: 最低 4個
- 内部リンク: 最低 1個（推奨 2個以上）

### 品質スコア（0-100点）
- S (90+): 即公開OK
- A (75-89): 公開OK、改善余地あり
- B (60-74): 公開可、要監視
- C (60未満): 公開停止、リライト必要

### 品質チェック項目（10点満点 × 10項目）
1. 文字数（2000字以上）
2. h2/h3 構造
3. 内部リンク数
4. アイキャッチ画像設定
5. メタデータ完備
6. テンプレート残骸なし
7. Claude JSON漏れなし
8. 年号の正確性
9. フックワード（タイトル魅力度）
10. テキスト重複なし

## リード文テンプレ
記事冒頭3段落は以下構造:
- 第1段落: 5W1H（誰が、いつ、何を、どこで、なぜ、どうやって）
- 第2段落: 背景・経緯（1-2文）
- 第3段落: 重要性（1文）

## 速報の判断基準
以下に該当するニュースのみ【速報】としてタイトルに付ける:
- 24時間以内に発表・発覚した新情報
- ゴシップ・スキャンダル・炎上
- 突発的な出来事（緊急発表、電撃発表）

以下は速報ではない:
- まとめ記事
- ランキング・チャート記事
- 分析・考察・比較記事

## AI語尾禁止フレーズ
以下のフレーズは使用禁止（post_write_sanitize.py で自動検出）:
- ですよね / でしょうか / なのです
- 皆さんもご存知の / と言われています / 注目されています
- きっと / ぜひ / まさに
- 感嘆符は1記事につき3個まで

推奨表現: 断定調、5W1H、プレスリリース調

## K-POP文脈キーワード必須ルール
全タイトルに以下のいずれかを必ず含める:
- K-POP関連語: K-POP / 韓国 / 韓国アイドル
- 具体アーティスト名
- K-POP固有イベント語: カムバック / MAMA / Mカウントダウン

## サムネイルルール（v6）
- テキストゼロ（焼き込みテキスト禁止）
- 実写真優先（YouTube公式MV → Wikimedia → Unsplash → フォールバック）
- Vision品質検証: 90点以上で合格
- abstract記事のみAI画像許可（韓国ドキュメンタリー調）

## 1日の投稿上限
- safety_config.json で定義: 15本/日（デフォルト）
- 異常検知: 25本/日以上で警告
