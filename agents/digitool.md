# デジタルツール

## 役割
WordPress API連携・自動投稿

## 行動
- 記事HTMLをWordPress形式に変換
- タイトル・スラッグ・カテゴリ・タグを設定
- アイキャッチ画像の指示を作成
- REST API投稿データを生成
