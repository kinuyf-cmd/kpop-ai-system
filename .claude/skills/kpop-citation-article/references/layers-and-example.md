# Layer 別の詳細と記事例

SKILL.md から参照。Layer 1/2 の違いと、引用記事の完成例を示す。

## Layer 1: 主要メディア引用記事

- **シグナル源**: 韓国系の主要メディア(韓国紙の日本語版、K-POP専門英語メディア等)。
  採用媒体は `~/.kpop_recovery/M3_stage3.2_design_20260520.md` の採用可否
  マトリクスでオーナーが確定したリストに従う。
- **本数**: 1日30-50本が上限。品質ゲートを通った数だけ公開する。
- **記事のトーン**: ニュース報道の紹介。事実中心、速報性を重視。
- **カテゴリ**: news / comeback / chart など出来事に応じて。

## Layer 2: リリース引用記事

- **シグナル源**: チケットサイト、PRTIMES 等のプレスリリース。
- **特徴**: プレスリリースは元々「報道・引用されることを前提に公開」されて
  いるため、Layer 1 より引用の自由度は高い。ただし主従関係・出典明記の
  原則は同じく守る。
- **記事のトーン**: 告知・案内。日時・会場・申込方法など実用情報を正確に。
- **カテゴリ**: event / popup / live など。
- **注意**: 日時・価格・申込先は誤ると読者に実害が出る。プレスリリースの
  記載と1字1句照合する(Factcheck の重点)。

## 翻訳・サムネ・ハルシネーション制御

Layer 1/2 とも SKILL.md の §4(翻訳)・§5(サムネ)・§6(ハルシネーション)
を同じく適用する。

## 引用記事の完成例(Layer 1・カムバック速報)

入力シグナル: あるメディアが「グループ X が来月カムバック」と報じた記事。

出力(HTML、抜粋・構造を示すための簡略例):

```html
<h1>【速報】X、来月◯日にカムバック決定 新ミニアルバムのタイトル曲も公開</h1>
<p>韓国の音楽シーンで人気の X が、約8か月ぶりとなるカムバックを発表した。
所属事務所が公式に明らかにしたもので、新しいミニアルバムを引っさげての
活動再開となる。</p>

<h2>カムバックの概要</h2>
<p>報道によると、X は来月◯日に新ミニアルバムをリリースする。タイトル曲は
「(曲名)」で、◯日に先行公開される予定だという。</p>
<blockquote>「メンバー全員が新しいコンセプトに自信を持っている」
<cite>— メディア名「原題」</cite></blockquote>

<h2>前作からの歩み</h2>
<p>X は前作のタイトル曲で音楽番組1位を獲得し、ロングヒットを記録していた。
今回のカムバックはその流れを受けたもので、ファンの期待も高い。</p>

<h2>今後のスケジュール</h2>
<p>カムバックに合わせ、音楽番組への出演やショーケースの開催も予想される。
詳細は今後の発表を待ちたい。</p>

<hr>
<p class="kpop-citation-source">引用元:
<a href="https://example-media.com/article/12345" rel="nofollow noopener">メディア名「原題」</a>
(取得日 2026-05-20)</p>
```

この例で守られていること:

- 直接引用は `<blockquote>` 1か所のみ(全体の20%未満)。
- 残りは自社による要約・背景説明。「前作からの歩み」は引用元に無い独自の
  整理だが、**確実な既知情報の範囲**にとどめている(憶測ではない)。
- 「予想される」「期待も高い」は引用元のトーンを超えた断定をしていない。
- 末尾に引用元リンク + 取得日。`rel="nofollow noopener"`。
- インライン `style` を使わず、引用元は `.kpop-citation-source` クラス。
- H2 が3個。

## やってはいけない例

- 原文を段落ごとに日本語化しただけ(主従関係なし=引用の要件を満たさない)。
- 「X は世界的に最も成功したグループだ」のような引用元に無い評価の付加。
- 引用元が「検討中」としか書いていないのに「決定した」と断定。
- 日付・会場・価格を記憶や推測で補う(Layer 2 で特に危険)。
