# Event Collector

## 1. 目的

K-POP のコンサート・ライブ・イベント情報を自動収集し、
イベント情報のハブにする。100点計画 G項目の達成が狙い。

## 2. 技術スタック

- The Events Calendar プラグイン
- WordPress カスタム投稿タイプ `event`

## 3. 情報源

- チケット販売サイト(ぴあ / e+ / Lawson / ticketboard)
- 公式アーティスト SNS / 事務所公式サイト
- 韓国メディア(ライブツアー発表)

## 4. 収集対象

- 日本国内コンサート
- 韓国コンサート(オンライン視聴可能なもの)
- 主要海外公演(Coachella, KCON 等)
- ファンミーティング / フェス出演

## 5. イベント情報の構造

イベント名 / アーティスト / 開催地 / 開催日時(複数公演対応)/
チケット販売開始日 / 価格帯 / チケットリンク。

## 6. 投稿自動化

- The Events Calendar に直接登録
- 関連記事も自動生成(news カテゴリ)
- アイキャッチ: アーティスト画像

## 7. カレンダー表示

- 月表示 / リスト表示
- フィルタ(アーティスト / 地域 / 期間)
- 検索可能

## 8. 100point-rubric-judge G項目との連動

| G項目 | 基準 |
|---|---|
| G-1 | The Events Calendar の稼働 |
| G-2 | 情報源との連携 |
| G-3 | カレンダー表示の動作 |

## 9. 安全設計

- 日付・場所の二重チェック
- チケット販売情報は公式ソースのみ
- 中止・延期の即時反映(古い情報を残さない)
- 出典は [[citation-rules]] に従い明記する
