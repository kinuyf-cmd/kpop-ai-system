# Citation Rules

## 1. 目的

記事の引用・出典を著作権法に沿って正しく扱う。著作権遵守・
SEO評価の維持・サイトの信頼性確保が狙い。

## 2. 引用ルール(著作権法 第32条 準拠)

- **主従関係**を明確にする(自社記事が主、引用が従)
- 引用率は記事全体の **20%以下**
- 引用部分は `<blockquote>` で明確に区別する
- 引用の**必然性**(なぜその引用が必要か)を満たす
- **出典を明記**する

## 3. 出典明記フォーマット

- メディア名 + 記事タイトル + URL + 取得日
- `<cite>` タグ + リンク
- 公式情報源を優先(SM Entertainment / HYBE / Spotify 公式 等)

## 4. ライセンス確認

- 画像: 公式素材 / Creative Commons / 自社撮影 のみ
- 動画: 公式公開のものだけ embed
- 音楽: 歌詞の引用は不可、曲タイトルのみ可

## 5. 引用元の階層(信頼度)

- **Tier 1(高)**: 公式リリース、Billboard、Korea JoongAng Daily
- **Tier 2(中)**: 大手メディア、Forbes Korea
- **Tier 3(参考程度)**: 個人ブログ、SNS

## 6. NG 引用

- 全文転載(改変なし)
- 出典のない数値・統計
- 不確かな噂レベルの情報

## 7. kpop-article との連携

記事生成時に: 引用ブロックを検出 → 引用率を自動計算 →
出典明記の有無をチェック → `kpop-article` の HARD_FAIL 条件に組み込む。

## 8. 100point-rubric-judge C項目との連動

- C-2: 引用ルールの文書化 → 本スキルの存在で 1点。

## 9. 出力ルール

違反を検出したときのみ警告する。正常時は無音(余計な出力をしない)。
警告には該当箇所と違反理由(引用率超過・出典なし等)を添える。
