# KPOPJournal ライティングガイドライン v1.0

> 対象: 全AI記事生成エージェント（kpop_pipeline / beauty / lifestyle / strategy / comparison / chart）
> 更新日: 2026-04-22

---

## 1. 基本スペック

| 項目 | 基準 | 備考 |
|------|------|------|
| 本文文字数 | 1,500〜2,500字 | 深堀り系は3,500字まで許容 |
| H2見出し | 最低4本 | 読者の離脱を防ぐスキャナビリティ確保 |
| H3見出し | H2あたり1〜3本 | 必須ではないが推奨 |
| 画像想定 | 3段落に1枚 | alt属性は必ず日本語で設定 |
| 内部リンク | 最低2本 | 関連記事への自然な誘導 |
| 導入文 | 120字以内 | 最初の1文で読者のフックを作る |
| メタディスクリプション | 120字以内 | 検索結果での表示を意識 |

## 2. 導入文（リード）のルール

- **120字以内**で、記事の核心を伝える
- 疑問形・数字・感情ワードのいずれかを含める
- 「この記事では〜を解説します」型の説明文は避ける

### 良い例
> BIGBANGが8年ぶりにコーチェラのステージへ。なぜ今、世界が彼らの復活を待ち望んでいるのか？

### 悪い例
> この記事ではBIGBANGのコーチェラ出演について解説します。

## 3. 専門用語の扱い

K-POP用語は初出時に必ず併記する。読者の7割は検索経由の新規ユーザー。

| 表記ルール | 例 |
|------------|-----|
| 日本語（英語/補足説明） | カムバック（comeback/新曲発売） |
| グループ名は正式表記 | BLACKPINK（ブラックピンク）※初出のみ |
| 略称は正式名のあとに | LE SSERAFIM（ルセラフィム、以下ルセラ） |

## 4. 記事構成テンプレート

```
[導入文: 120字以内のフック]

## H2-1: トピックの概要・背景
（何が起きたか / なぜ注目されているか）

## H2-2: 詳細・分析
（具体的な内容を深堀り）

## H2-3: ファンの反応・SNSの声
（X/コミュニティの反応を交えて臨場感）

## H2-4: 今後の展望
（次に何が起きるか / 読者が注目すべきポイント）

## まとめ
（要点3行 + CTA）
```

## 5. CTA（Call to Action）

記事末尾に必ず読者アクションを促す一文を入れる。

### パターン例
- 「あなたの推しの見どころをコメントで教えてください！」
- 「気になるメンバーがいたらSNSでシェアしてくださいね」
- 「他の〇〇関連記事もチェック >>>（内部リンク）」

## 6. SEOチェックリスト

- [ ] タイトルに主要キーワードを含む（32字以内推奨）
- [ ] H2にサブキーワードを自然に含める
- [ ] 導入文の最初の100字にキーワードが出現する
- [ ] 画像altテキストにキーワードを含む
- [ ] 内部リンク2本以上（うち1本はカテゴリ内の関連記事）
- [ ] メタディスクリプションにキーワード + アクション誘発

## 7. NG表現

| NG | 理由 | 代替 |
|----|------|------|
| 「〜と話題になっています」（根拠なし） | ファクト不在 | 具体的なソース（X投稿数等）を添える |
| 「衝撃の事実！」「ヤバすぎる！」 | 煽りすぎ | 感情は適度に。事実ベースで書く |
| 英語の直訳体 | 不自然 | 自然な日本語に再構成 |
| テンプレ表現「いかがでしたか？」 | 陳腐 | 具体的な問いかけに変える |

## 8. ペルソナ別チューニング

記事のカテゴリに応じて、対象ペルソナのトーンに寄せる。

| ペルソナ | トーン | 文体 |
|----------|--------|------|
| コアファン（25-34歳） | テンポよく・共感重視 | ですます調、適度な感嘆 |
| K-culture興味層（18-24歳） | カジュアル・親しみ | ですます調、絵文字控えめOK |
| 大人ファン（35-44歳） | 丁寧・知的好奇心 | ですます調、データ引用多め |
