# 投稿ルール（カビゴン管轄）

## 投稿対象ファイル
- final_post.md のみ（絶対ルール）

## 投稿禁止
- review_log.md
- 3_arceus.md のような審査レポート
- JSONログ
- 質問文・会話文
- HTMLのない記事
- タイトルなし

## 投稿前チェック（BLOCK条件）
1. ファイルが final_post.md であること
2. タイトルが存在し、# で始まらないこと
3. 本文にHTML要素があること
4. 審査レポートの文言が混入していないこと
5. 質問文・AI定型文が含まれていないこと
6. 文字数基準を満たしていること
7. h2が2つ以上あること

## 投稿時間
- 速報：検知から30分以内
- 解説/比較/収益：7:30 / 11:30 / 20:00
- ライブ・チケット：18:00
- 特集：土日10:00
- K-POPチャート：毎週月曜 7:30

## 投稿後フロー（完全自律型・自己修復ループ）

### 基本方針
- 投稿後の品質問題はすべて自律修正する
- 人間への確認依頼・レポート通知は禁止（重大障害除く）
- 修正提案で止まらず、必ず修正実行まで完了させる
- 最大3回の修正ループを行う
- 3回失敗時のみ draft に戻す

### フロー
投稿 → post_audit.sh → 自動修正 → 再監査（最大3回） → 完了 or draft化

### 必須監査項目

**A. 文字・本文品質**
- `\uXXXX` 文字化けなし
- HTML文字数 3000以上
- h2 2個以上
- title/h1/導入の整合性

**B. 内部リンク**
- 主軸記事（post_id=2214）へのリンク 2本以上
- 旧URLでなく最終URLへ直接リンク

**C. HTTP・インデックス**
- HTTP 200
- noindex/canonical 正常
- 301チェーンなし

**D. スラッグ**
- 英語のみ（日本語禁止）
- 5〜8単語以内・簡潔
- 不要な数字・日付含めない（例：20260410 NG）

**E. カテゴリ**
- 記事内容と一致・1〜2個まで
- 誤カテゴリ（「広告」等）禁止

**F. サムネイル**
- 必ず設定されている
- 文字化けなし・視認性確保

**G. SEO**
- タイトル32文字前後・メタディスクリプション110〜130文字

### 自動修正ルール
| 問題 | 修正 |
|---|---|
| 文字化け | Unicodeデコードして再投稿 |
| HTML文字数不足 | SEO補強追記 |
| 内部リンク不足 | 主軸記事リンク自動挿入 |
| 301不足/チェーン | Redirectionで自動追加・1発に統一 |
| スラッグNG | 自動再生成して更新 |
| カテゴリ不一致 | 適切カテゴリに修正 |
| サムネ未設定 | 再生成→差し替え |
| SEO不足 | タイトル・ディスクリプション再生成 |

### 禁止事項
- 「どうしますか？」で止まる
- 修正提案だけ出す
- 人間判断待ち
- 不完全状態で公開維持
