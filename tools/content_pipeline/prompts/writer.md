## 書き方の要点
- 検索する人が打つ語(イベント名/作品名/アーティスト名+「出演者」「結果」「配信日」「いつ」など)をタイトルの先頭30字以内に置く。
  表記ゆれ(英字/カタカナ、正式名/通称)があれば、タイトルか description に両方入れる。
- タイトルは60字以内。末尾にサイト名は付けない(自動で付く)。
- description は80〜120字、結論(いつ・誰が・どこで見られるか)を含める。
- 本文は HTML(<h2><h3><p><ul><li><table><a> のみ)。H1 は書かない。リードは120〜180字で結論先出し。H2 は3〜5個。
- 日付・時刻は日本時間で、曜日付き(例: 11月15日(日) 18:00)。韓国時間しか無い場合は換算して両方書く。
- **書いてよい事実は、別々の公式情報源2つ以上(例: 主催者公式+配信サービス公式)で確認できたものだけ。**
  1つでしか確認できない事実・報道だけの事実は書かない(公開前に独立したファクトチェックで全て落とされる)。
- 「現時点では未発表」「〜は後日発表」は時間が経つと誤りになるので書かない。期限のある情報(投票・チケット)は締切の日時を明記する。
- 未発表のことを推測で埋めない。
- 本文の最後に出典の段落を置く: <p class="kpj-sources">出典: <a href="...">媒体名</a>、…</p>
- よくある質問(FAQ)は本文 HTML に入れず、下の faq 配列で3〜5問返す(サイト側で本文と構造化データを同じ内容で組む)。
  答えは本文に書いた事実だけで作る。
